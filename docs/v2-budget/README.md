# STM v2 at UCSD: budget

`STM_v2_budget.xlsx` is the budget for building a second STM at UCSD. It is written for Prof. Oscar Vasquez and the UCSD budget office. It has two tabs:

- **v2 budget.** This is the main tab. Every part is grouped by what it does in the microscope. Each part has a plain description, a note on whether it is new in v2 and why, the vendor, the part number, the quantity, the price and a link. Section 8 lists items a UCSD lab may already have. Choosing **Yes** in its last column takes that item off the total.
- **v1 (what it cost).** This tab shows what the first instrument actually cost, $1,375.93. The Amazon purchases appear as one total.

| | |
|---|---|
| v2 total if UCSD supplies nothing in section 8 | $2,821.24 |
| v2 total if UCSD supplies everything in section 8 | $1,817.94 |
| v1 actual cost | $1,375.93 |

Prices were checked on 2026-10-21, in USD. The JLCPCB circuit boards are priced at what v1 paid in July 2026. The high-voltage driver circuit is not designed yet, so its parts are estimates.
