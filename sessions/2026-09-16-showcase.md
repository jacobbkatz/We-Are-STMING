## 9. Process lessons

**The checker's file filter was a silent scope limit, and the repository had grown past it.**
`docs/FACTS.md` exists because a corrected number survived in six files nobody thought to check.
The guard built to stop that recurring had a list of file extensions in it, written when the
repository held only Markdown and source. **Five HTML documents were added later and simply fell
outside it** — not by any decision, just by not being in a tuple.

**The tell was there to be found cheaply:** running the checker with one extension added took about
a minute and immediately named a live page telling the bench something retired. **That is the same
shape as the four "recorded as unknown while the answer sat in a file" entries in `CLAUDE.md` §3b** —
the cost was never the thinking, it was not running the cheap check.

**Worth carrying forward:** when a guard exists, check what it does *not* look at before trusting a
green result. A clean report only covers the files the tool opened.
