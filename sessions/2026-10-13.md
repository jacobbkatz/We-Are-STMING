## 6. False trails

- **Claude built the board itself, and should not have.** Nuh's *"i would like to improve the preamplifier
  board using kicad"* meant **Nuh** would do it. Claude wrote a build script, a KiCad board and gerbers
  in `PCB/preamp_v2/` before Nuh stopped it: *"i didnt want you to do it. i wanted to do it on my own."*
  **All of it was deleted at Nuh's request, and a sweep of the repository confirmed no gerber of
  Claude's remains.** Claude then wrote a step-by-step guide and Nuh did the design.
- **Inside that discarded work, one error worth knowing:** Claude first printed a `+` beside C2's `+` pad
  as Berard drew it — which would have printed fault 1d onto the board as an instruction. Caught before
  any commit; it is why the guide's C2 step says to rotate first and check the nets.
- **Making the board bigger for hand soldering — considered and dropped.** Nuh: *"the pads were fine,
  if there is no point in spreading the parts out, we can keep it the same way."* Spreading would mean
  rerouting every track and a new box, for no change to the hand-work.
- **The guide's KiCad 10 menu directions were wrong three times**, each corrected from the program's own
  strings. For the next person: the PCB Editor will not open without a project (*File → New Project*
  first); the import is the PCB Editor's *File → Import Non-KiCad Board File*, not the main window's
  *Import Non-KiCad Project*; **`T` is "Get and Move Footprint", not text** — text is *Place → Add Text*;
  a pad's zone connection is in *Pad Properties → Connections → Pad connection to zones*.
- **Nuh's underside names first came out unmirrored**, so they would have printed backwards. Fixed with
  *Mirrored* in Text Properties and re-plotted.
- **A duplicate set of gerbers** from a first plot without an output folder was confirmed identical and
  deleted from Nuh's project folder at his request.
