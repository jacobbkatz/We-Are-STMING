**Method note, because it matters:** the correlations only reproduce **after the tilt is removed
from each pass**. On the raw undetrended arrays the same test gives +0.741 for the wide line and
+0.880 for the narrow one, because the fixed −0.1 to −0.2 counts-of-Z-per-count-of-X tilt dominates
both and makes everything correlate with everything. **Any correlation quoted from this data has to
say whether it was detrended.** The log's figures are the detrended ones.

## 4. New faults

**None found in the instrument.** One process observation, recorded because it cost time here:

- **A number written by hand into a document is not the number in the file it came from.** The first
  draft of the review page carried a data block that had been typed out rather than generated from
  the CSVs. It rendered without error and produced three plausible-looking figures — 494, 67 and 17
  counts — **none of which were right.** It was caught only because the page prints the RMS of each
  curve next to it and 494 did not match the 636 computed minutes earlier. **The fix was to inject
  the generated file programmatically.** A chart that does not display a number you can check
  against something else would have shipped wrong.

## 9. Process lessons

- **Recomputing a result from the committed raw files is cheap and it is worth doing before
  presenting it.** Six figures were checked here in a few minutes and all six held. That is worth
  more than the checking cost, because the page can now say the numbers were reproduced
  independently rather than transcribed.
- **Say whether a correlation was detrended.** Undetrended, this data set's numbers are roughly
  +0.75 and +0.88 and look like a triumph. They are the tilt correlating with itself.
- **A figure that prints its own summary statistic catches its own bad data.** That is the only
  reason §4's typed-out data block was found before it was published.
