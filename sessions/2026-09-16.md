# Session 2026-09-16

**Who was there:** Jacob, with Claude on the web (cloud session, no bench access).
**Type:** setup only. **Nothing was powered and nothing was measured.**
**Goal for the session:** power the preamp through the controller for the first time and take the
first `ADCR` reading with the ADC inside its input conditions.

**Outcome: the goal was not reached, for a reason nobody had written down.** Jacob was at a Windows
computer that had never run this project, using Claude Code on the web. **A web session runs in a
cloud container and cannot reach a USB port**, so it cannot run `stm_console.py` against the
Teensy. Every previous bench session ran Claude Code on the computer itself, on Nuh's machine.
Jacob stopped to install Claude Code desktop, Git and Python and restart there. **This log exists so
that the restart session, and any future first-time machine, does not lose an evening to the same
thing.**

## 6. False trails

- **Two rounds of instructions were written for the wrong situation** before the cause surfaced:
  first a bench list assuming the repository was already on the machine, then a clone-and-install
  list assuming the user would type the commands. Both are superseded by the desktop restart, and
  the second is kept as the README's Windows section because it is still the setup that machine needs.
- **This session is on a cloud branch, not `main`.** Claude Code on the web works on
  `claude/funny-cori-xttv3q`; the session-start hook said so and said not to push to `main` unasked.
  §8 below says what to do about it.

## 9. Process lessons

- **"The Windows machine" was a fact about a person's computer, written without the person.** The
  inventory rule in `CLAUDE.md` §3d already says what is in the room is not in any design file.
  **Which computers run the project is the same kind of fact**, and it was never in the inventory.
  Now it is.
- **The web session did the reading and the arithmetic, and that part was not wasted.** The
  node-by-node check of what the controller puts on the preamp is in the plan for the desktop
  session to inherit, and the `ADCR` expectation is now a number derived from last night's meter
  reading rather than a range copied forward.
